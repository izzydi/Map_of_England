# Map of England

A geospatial data-visualization project focused on mapping England and presenting the resulting analysis as an interactive/rendered HTML document.

## Repository contents

- [`Map_of_England.html`](Map_of_England.html) — rendered map/analysis output.

## Project focus

This repository showcases spatial-data visualization and map-based presentation. The original rendered report has been preserved so the project can be reviewed directly without altering the historical analysis.

## Viewing the project

Download `Map_of_England.html` and open it in a modern web browser. GitHub does not execute embedded HTML visualizations directly in the repository view, so local viewing or an HTML preview service gives the best result.

## Reproducibility note

Only the rendered HTML output is currently stored in the repository; the original source script/notebook is not present. The repository therefore serves primarily as a portfolio artifact of the completed spatial analysis.
